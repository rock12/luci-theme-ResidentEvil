# ☣️ Тема Resident Evil (Umbrella Corporation Edition) для OpenWrt LuCI

Тёмная тема оформления веб-интерфейса LuCI для роутеров OpenWrt (23.05, 24.10, 25.12+), стилизованная под секретный защищённый терминал безопасности **Umbrella Corporation** по мотивам культовой вселенной **Resident Evil**.

> 💡 **Основано на проекте:** [**luci-theme-proton2025**](https://github.com/ChesterGoodiny/luci-theme-proton2025) от [**ChesterGoodiny**](https://github.com/ChesterGoodiny).  
> Выражаем огромную благодарность автору оригинального проекта за современную архитектуру, поддержку ucode, высокую производительность и продуманную систему настроек!

## 🛠️ Что было сделано

### 🧟 1. Экран входа
* **Кинематографичный арт персонажей:** по краям экрана расположены Леон С. Кеннеди (в тактической экипировке R.P.D.) и Ада Вонг. Герои обрамляют рабочую область и не перекрываются полями ввода.
* **Терминал Umbrella Corporation:** форма входа оформлена как закрытый терминал безопасности `[ LEVEL 8 CLASSIFIED ACCESS ]`.
* **Атмосферные эффекты:** динамический тёмный дождь, стелющийся туман и летящие алые искры на фоне эмблемы Umbrella.

### 🩸 2. Дизайн и интерфейс LuCI
* **Цветовая палитра Umbrella:** глубокий тёмный карбоновый фон (`#080a0e`) с неоновым алым акцентным цветом (`#dc2626` / `#ef4444`).
* **Векторные логотипы:** оригинальный красно-белый зонт Umbrella Corporation в шапке и на экране входа.
* **Полупрозрачные стеклянные панели (Glassmorphism):** аккуратные тонкие рамки без лишней громоздкости и мягкое размытие заднего фона (`backdrop-filter`).
* **Осветление фонового арта:** обои внутри интерфейса сделаны ярче и контрастнее, персонажи хорошо видны.
* **Уведомление о пароле:** предупреждение «Пароль не установлен!» перенесено в верхнюю часть страницы с интерактивным крестиком `×` для закрытия (состояние сохраняется в сессии).
* **Модальные окна:** окно «Сессия истекла» и диалоги больше не заливают весь экран глухим чёрным цветом — сделано красивое полупрозрачное затемнение.
* **Центрирование:** системные блоки информации и статуса роутера выровнены строго по центру экрана.

### 📊 3. Интерактивные виджеты (Статус / Обзор)
* **Виджет температуры в реальном времени:**
  * Считывает данные термозон процессора и чипов Wi-Fi (MT7915 PHY0, MT7915 PHY1).
  * Все 4 датчика компактно расположены **в одну строчку** без переносов.
  * Цветные индикаторы нагрева (Зелёный — Норма, Жёлтый — Тепло, Оранжевый — Горячо, Красный — Критично).
  * Отображение текущей температуры, пиковых значений и пульсирующих точек активности.
* **Виджет мониторинга служб:**
  * Карточки активных демонов (Dnsmasq, Dropbear, Uhttpd).
  * Названия сервисов выводятся полностью и не обрезаются.
  * Карточки по высоте, стилю и анимациям полностью приведены к единому виду с датчиками температуры.
  * Добавлена кнопка `[+ Добавить]` для быстрого добавления отслеживаемых служб.
* **Центр управления виджетами:**
  * Отдельная кнопка `[⚙ Настройки виджетов]` с поиском и тумблерами для быстрого включения/отключения нужных блоков.

### 📦 4. Сборка и автоматизация релизов
* **Поддержка всех пакетных менеджеров:** автоматическая сборка пакетов `.ipk` (для OpenWrt 23.05/24.10) и нового формата `.apk` (для OpenWrt 25.12+).
* **GitHub Actions CI/CD:** настроен автоматический пайплайн сборки пакетов на базе официальных OpenWrt SDK при публикации релизов.

## 🚀 Установка одной командой

Подключитесь к роутеру по SSH под пользователем `root` и выполните:

```sh
wget -qO- https://raw.githubusercontent.com/rock12/luci-theme-ResidentEvil/main/install.sh | sh
```

Скрипт сам определит версию системы (`apk` или `opkg`), скачает подходящий пакет из последнего релиза, установит его и активирует тему в LuCI.

> После установки обновите страницу в браузере с очисткой кэша: **Ctrl + F5**.

## 🔄 Обновление

Для обновления темы до актуальной версии повторите команду:

